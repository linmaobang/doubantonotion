# 豆瓣同步到 Notion

一个 Chrome 扩展：把豆瓣上的图书、电影、剧集——连同封面、简介，以及你自己的状态、评分、短评、书评和读书笔记——保存到 Notion 数据库。可以一条一条存，也可以批量导入，还可以定时自动同步。

## 能做什么

- **一键保存**：在豆瓣条目页点一下，信息、封面、简介都存进 Notion；顺手标「想读 / 读过」、打星。
- **批量导入**：导入你在豆瓣的全部标记，或者任意列表（豆列、标签、Top250、别人的书单、「选电影」页面），逐条挑选后再导。
- **带走你写的东西**：书评、影评、读书笔记会放进对应条目的页面正文。
- **自动同步**：定时把豆瓣上的新标记、状态变化同步过来。
- **自动建库**：只要给一个 Notion 页面（空白页也行），数据库和字段都由插件建好；已有的库只补缺少的字段，原有字段不动。
- **适配你自己的库**：可以选写进哪个数据库，也可以在图形化的「字段对应」窗口里决定每一列放什么。
- **侧边栏**：可以固定在浏览器一侧，不挡页面，跟着你浏览的豆瓣页面自动变化。

## 安装

1. 下载本仓库（Code → Download ZIP）并解压。
2. 打开 `chrome://extensions/`，打开右上角「开发者模式」。
3. 点「加载已解压的扩展程序」，选择解压后的文件夹。

需要 Chrome 116 或更新的版本（侧边栏要用到）。

## 三步上手

1. **建一个 Notion 集成**：打开 [Notion 集成页面](https://www.notion.so/profile/integrations)，新建一个「内部集成」，复制它的 Token。
2. **填设置**：点插件图标右上角的齿轮打开设置页，填入 Token，再粘贴一个 Notion 页面链接（空白页就行）。
3. **给页面授权**：在 Notion 里打开这个页面，右上角「…」→「连接」→ 添加你的集成。

设置页顶部显示「✓ 一切就绪」就可以用了。修改会自动保存，底部的「保存」按钮点不点都行，点了会再检查一遍，然后就可以放心关掉页面。

> 不先设置、直接用某个功能也没关系：插件会给出「去填写 Notion Token」「去选一个 Notion 页面」这样的按钮，点了直接打开设置页并定位到要填的那一栏；填好后可以一键回到原来的页面接着做。

## 使用

### 保存一本书 / 一部电影

打开豆瓣条目页 → 点插件图标 → 确认预览 → 点「保存到 Notion」。保存后按钮会变成「在 Notion 中打开」。

- **我的标记**：可以选「想读 / 在读 / 读过」（影视是「想看 / 在看 / 看过」）并打 1~5 星，会写进「状态」「我的评分」「标记日期」。登录了豆瓣、并且已经标记过这一条时，会自动带上。选「不标记」则不改动 Notion 里已有的标记。
- **电影 / 剧集**：豆瓣偶尔分错，可以在卡片上切换。
- **换一个库**：默认存进设置里的库；点「换一个库」可以改存到任意一个已有的数据库，或者新建一个。每次打开都会回到默认库，避免误存。
- **不会重复**：同一个豆瓣链接已经在库里时，保存会更新那一条。

### 侧边栏

点弹窗右上角的「侧边栏」，或者在设置页「插件界面」里选「侧边栏」：

- 固定在浏览器一侧，不挡页面，点豆瓣页面也不会关掉；
- 切换标签页、打开另一本书或另一个列表时自动跟着变；同一个页面刷新时不会打断你正在选的标记；
- 「选电影」这类往下滚动加载的页面，加载更多后点右上角的「重新读取」。

侧边栏在左边还是右边，由 Chrome 的「设置 → 外观 → 侧边栏位置」决定，设置页有直达按钮。想改回弹出小窗，在设置页「插件界面」里选回来即可。

### 批量导入

从弹窗下方的「批量导入」卡片进入（设置页顶部也有入口）。有两种来源：

**我的豆瓣标记**
- 登录了豆瓣会自动识别你的账号（也可以粘贴个人主页链接），勾选想读 / 在读 / 读过、想看 / 在看 / 看过；
- 会连同你的状态、评分、短评、标签、标记日期一起导入；
- 勾选「同时导入我写的书评 / 影评和读书笔记」，会把它们放进对应条目的页面正文：每篇评论一个标题（链接到原文）加日期和全文；笔记放在「我的读书笔记」下，每条带页码。图片不搬运，会留看原文的链接。重新导入只追加还没有的，不会重复。

**豆瓣上的列表**（豆列、图书标签、Top250、别人的读过 / 想读、「选电影」「选剧集」……）
- 在豆瓣打开这个列表页，点插件图标 →「挑选并导入这个列表」；或者在批量导入页切到「豆瓣上的列表」，粘贴链接；
- 能翻页的列表会顺着「后页」读，可以设定最多读几页（标签页可能有几百页）；滚动加载的页面只能读到已经显示出来的，先在页面上多点几次「加载更多」；
- 列表页上只有标题和评分，所以每条都会打开详情页补全信息；
- 会在「来源」字段记上出处，比如「豆列：五颗星经典系列」「标签：科幻」；同一本书从多个列表导入，来源会累加。

**挑选**：读取后会列出全部条目，带封面小图。
- 按类型、状态、标记年份、我的评分筛选，或者搜标题、作者、导演；按标记时间、评分、标题排序；
- 「全选这些 / 取消这些」只作用于当前筛选出来的条目；按住 Shift 点击可以连选；
- 默认勾选还没导入的。标着「已在 Notion」的默认不勾，勾上就会用豆瓣的最新信息更新它。

**写进哪个数据库**：挑选页下方可以为图书、电影、剧集分别选——默认库、新建一个（名字默认是来源）、任意已有的库，或者「和电影用同一个库」（剧集专用）。换了库，「已在 Notion」会按新库重新判断。插件会记住每个来源上次选的库。
> 只是想按来源分开看的话，也可以不建新库：在默认库里用「来源」字段建几个筛选视图。

**导入中**：可以随时暂停；切到别的标签页时，进度显示在标签页标题上；关掉页面再打开会提示继续，勾选也会保留；导完可以直接打开对应的 Notion 数据库。

### 自动同步

在设置页打开「自动同步」，选好豆瓣账号、要同步的列表和频率（每 6 小时 / 12 小时 / 每天）：

- 新标记的条目，会补全详情后写进 Notion；
- 改了状态（比如「想读」→「读过」）、评分、短评、标签的，会更新 Notion 里那一条；
- 第一次运行只记下现在的状态，不会把以前的全部导一遍——以前的请用批量导入；
- 写进的库和你批量导入「我的标记」时选的一样，没选过就用默认库。

浏览器开着时才会运行；每次最多处理 30 条，多的过 15 分钟接着做；批量导入进行中时会跳过这一轮。弹窗底部会显示上次同步的结果。

### 数据库和字段对应

**自动建库**：第一次保存时，插件在你选的页面里找名为「我的书库」「我的影院」「我的剧集」（或「图书」「电影」「Books」「Movies」等）的数据库——有就沿用，只补缺少的字段；没有就新建，自带「状态」「我的评分」「标记日期」「短评」「我的标签」「来源」等全部字段。不想等第一次保存，可以在设置页点「现在就建好 / 补全」。也可以在「已有数据库（可选）」里指定页面之外的库。

**字段对应**：插件默认按列名自动对应（「书名」「标题」「Name」都会当成标题）。库用的是自己的叫法时，点设置页每种类型后面的「⇄ 字段对应」（批量导入时选了一个没设置过的已有库，也会自动弹出）：
- 每一行是数据库的一列，右边选它放豆瓣的哪项信息，只列出能放进这种列的；选「不写入」的列插件不会再碰；
- 没对应列的信息，可以让插件自动新建列来放（不会碰同名的已有列），也可以不要；
- 还可以设置正文放不放「简介」「作者简介」、要不要用封面做页面封面；
- Notion 的「状态」类型列只写它已有的选项，避免保存失败。

设置按数据库保存，单本保存、批量导入、自动同步都会用它。

**会写进的字段**
- 图书：书名、副标题、作者、译者、出版社、出品方、出版日期、页数、定价、装帧、丛书、原作名、ISBN、豆瓣标签、豆瓣评分、封面、链接；正文放简介和作者简介
- 电影 / 剧集：片名、原名、年份、导演、编剧、主演、类型、国家 / 地区、语言、上映日期 / 首播日期、片长 / 单集片长、集数、IMDb、豆瓣标签、豆瓣评分、封面、链接；正文放简介
- 我的标记：状态、我的评分、标记日期、短评、我的标签；从列表导入时还有「来源」

## 常见问题

**提示「找不到这个数据库或页面」**
在 Notion 里打开那个页面（或数据库），右上角「…」→「连接」→ 添加你的集成。插件只能访问你授权过的页面。

**豆瓣要求安全验证 / 插件图标上出现红色「!」**
豆瓣偶尔会要求做一次验证。点提示里的链接打开豆瓣，等页面正常显示（有验证就按提示完成），再回来点「继续」或「立即同步一次」。插件不会尝试绕过验证。

**为什么批量导入这么慢？**
为了不让你的 IP 被豆瓣限制，插件刻意放慢了速度：列表每页间隔 1.5~2 秒，详情页每条间隔 3~5 秒（随机）。豆瓣返回「请求太频繁」时会自动等 1 分钟、3 分钟再试。导入可以暂停、可以关掉页面下次接着来。

**有的标记没导进来**
只能读到**公开**的标记、书评和笔记，设为「仅自己可见」的不会出现。写了书评但没标记过的书不会单独导入。

**封面没显示**
豆瓣图片有防盗链，插件会下载封面再上传到 Notion。上传失败时会退回用外链，这种情况下 Notion 里可能显示不出来，重新保存一次通常就好。

**侧边栏打不开**
需要 Chrome 116 或更新的版本，在地址栏输入 `chrome://version` 可以查看。

## 权限和隐私

| 权限 | 用途 |
| --- | --- |
| `activeTab`、`scripting` | 读取当前豆瓣页面的信息 |
| `storage`、`unlimitedStorage` | 在本机保存设置和批量导入的进度 |
| `alarms` | 自动同步的定时任务 |
| `offscreen` | 自动同步时在后台解析豆瓣页面 |
| `sidePanel` | 把插件固定在浏览器侧边栏 |
| `book` / `movie` / `www` / `m.douban.com` | 读取条目页、列表页、你的标记和书评 |
| `declarativeNetRequestWithHostAccess` + `*.doubanio.com` | 给插件**自己**发出的请求（下载封面、读列表）加上豆瓣 Referer，不影响你的正常浏览 |
| `api.notion.com` | 调用 Notion API |

Token 和所有设置只保存在你本机的浏览器里，Token 只会发给 `api.notion.com`。插件不收集任何数据。

## 开发

项目没有构建步骤，改完代码在 `chrome://extensions/` 点刷新即可。

```
manifest.json  扩展配置
background.js  后台：保存到 Notion、查重、封面上传、豆瓣请求、自动同步调度
popup.*        工具栏弹窗；sidepanel.html 是同一套界面的侧边栏版本
options.*      设置页
import.*       批量导入页
mapping.js     字段对应窗口
setup.js       缺设置时引导到设置页对应的一栏，设置好后回到原处
scraper.js     豆瓣条目页的抓取（弹窗、批量导入、自动同步共用）
collector.js   从任意豆瓣列表页收集条目；读书笔记列表和全文页的解析
douban.js      豆瓣列表数据转换、合并详情、识别验证页
writings.js    书评 / 笔记的 HTML → Notion 段落，以及避免重复追加
selection.js   批量导入的筛选、排序、勾选
autosync.js    自动同步：找出变化、分批处理、状态文字
offscreen.*    自动同步时解析豆瓣页面的离屏文档
notion.js      Notion API 客户端、字段格式转换、字段对应
databases.js   找到 / 新建数据库，补全缺少的字段
config.js      字段名候选、字段说明、自动建库的结构
icons.js       界面图标（内嵌的 Lucide SVG）
tests/         单元测试（fixtures 里是豆瓣接口的真实返回样例）
```

运行测试（需要 Node 18+）：

```bash
npm test
```

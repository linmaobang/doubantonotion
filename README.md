# 豆瓣同步到 Notion

一个 Chrome 扩展：在豆瓣图书、电影、剧集的详情页点一下，就把条目信息、封面和简介保存到你的 Notion 数据库。

## 功能

- **打开即识别**：自动读取当前页面，自动区分图书 / 电影 / 剧集，不用刷新页面。
- **封面能正常显示**：豆瓣图片有防盗链，直接用外链在 Notion 里会裂图。插件会下载大图封面并上传到 Notion，同时设为页面封面。
- **不会重复**：同一个豆瓣链接已经在数据库里时，再次保存会更新原条目，而不是新建一条。
- **字段齐全**：
  - 图书：书名、作者、译者、出版社、出品方、出版日期、页数、定价、装帧、丛书、原作名、ISBN、标签、评分，以及正文里的「简介」和「作者简介」
  - 电影 / 剧集：片名、原名、年份、导演、编剧、主演、类型、国家/地区、语言、上映日期 / 首播日期、片长 / 单集片长、集数、IMDb、标签、评分，以及正文里的「简介」
- **适配你自己的数据库**：字段名按候选列表匹配（例如「书名」「标题」「Name」都行），类型也会自动转换（日期、数字、单选、多选、文本）。完整列表见 [config.js](config.js)。
- **自动建库**：只需选一个 Notion 页面（空白页也行），插件会在里面自动建好「我的书库」「我的影院」「我的剧集」，包括「状态」「我的评分」「标记日期」「短评」「我的标签」「来源」等全部字段。已经有数据库的话直接沿用，只补上缺少的字段，原有字段不动。
- **批量导入**：把你在豆瓣的想读/在读/读过、想看/在看/看过一次性导入 Notion，连同你的评分、短评、标签和标记日期；也可以导入豆瓣上的任意列表——豆列、标签页、Top250、别人的书单片单、「选电影」页面等，并逐条挑选（见下文）。

## 安装

1. 下载本仓库（Code → Download ZIP）并解压。
2. 打开 `chrome://extensions/`，打开右上角「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择解压后的文件夹。

## 设置

1. 在 [Notion 集成页面](https://www.notion.so/profile/integrations) 新建一个「内部集成」，复制 Token。
2. 点击插件图标右上角的 ⚙ 打开设置页，填入 Token。
3. 填一个 Notion 页面链接（空白页就行）。设置会自动保存并检查，顶部显示「一切就绪」就可以用了。
4. 在 Notion 里打开这个页面，右上角「…」→「连接」→ 添加你的集成。**这一步漏了会提示找不到页面。**

数据库会在第一次保存时自动处理：
- 页面里已有名为「我的书库」「我的影院」「我的剧集」（或「图书」「电影」「剧集」「Books」「Movies」等）的数据库 → 直接沿用，只补上缺少的字段；
- 没有 → 自动新建；
- 也可以在设置页「已有数据库（可选）」里指定页面之外的数据库，插件同样只补字段、写条目，不会新建。

不想等第一次保存，也可以在设置页点「现在就建好 / 补全」。

## 使用

打开任意豆瓣条目页 → 点插件图标 → 确认预览 → 点「保存到 Notion」。保存后按钮会变成「在 Notion 中打开」。

- **我的标记**：可以顺手选「想读 / 在读 / 读过」（影视是「想看 / 在看 / 看过」）并打星，会写进「状态」「我的评分」「标记日期」。如果你在豆瓣上已经标记过（需要登录豆瓣），会自动带上。选「不标记」则不改动 Notion 里已有的标记。
- **电影 / 剧集**：豆瓣偶尔分错，可以在卡片上切换。
- **换一个库**：默认存进设置里的库；点「会保存到…」旁边的「换一个库」，可以改存到任意一个已有的数据库，或者新建一个。每次打开弹窗都会回到默认库。

## 字段对应

插件默认按列名自动对应（例如「书名」「标题」「Name」都会当成标题）。如果你的库用的是自己的叫法，可以打开「字段对应」窗口手动调：

- 窗口里每一行是数据库的一列，右边选它放豆瓣的哪项信息，只会列出能放进这种列的信息；选「不写入」的列，插件不会再碰它；
- 一项信息只放一列，选了别的列会自动从原来那列移走；
- 豆瓣上还有、但没对应列的信息，可以让插件自动新建列来放（不会碰同名的已有列），也可以不要；
- 还可以设置页面正文放不放「简介」「作者简介」，以及要不要用封面做页面封面；
- 对 Notion 的「状态」类型列，只会写入它已有的选项，避免保存失败。

在哪里打开：设置页每种类型后面的「字段对应…」；批量导入挑选页的目标库下面。批量导入时选了一个还没设置过的已有数据库，窗口会自动弹出。设置按数据库保存，单本保存、批量导入、自动同步都会用它。

## 自动同步

在设置页打开「自动同步」，选好豆瓣账号（登录了豆瓣可以一键识别）、要同步的列表和频率（每 6 小时 / 12 小时 / 每天）。之后插件会定时检查你在豆瓣上最近的标记：

- 新标记的条目，会抓详情页补全信息后写进 Notion；
- 改了状态（比如「想读」→「读过」）、评分、短评、标签的条目，会更新 Notion 里对应的那一条；
- 第一次运行只记下现在的状态，不会把以前的标记全部导一遍——以前的请用批量导入；
- 写进的库和你批量导入「我的标记」时选的一样，没选过就用默认库。

几点说明：浏览器开着时才会运行；每次最多处理 30 条，多的过 15 分钟接着做；批量导入进行中时自动同步会跳过这一轮。
如果豆瓣要求安全验证，插件图标上会出现红色的「!」，弹窗底部也会提示，打开豆瓣让页面正常显示后，下次就会继续。

## 批量导入

有两种来源：

**我的豆瓣标记**：点插件弹窗右上角的「批量导入」。如果浏览器里登录了豆瓣，会自动识别你的账号（也可以手动粘贴个人主页链接），然后勾选想读/在读/读过、想看/在看/看过。会连同你的状态、评分、短评、标签、标记日期一起导入。

勾选「同时导入我写的书评 / 影评和读书笔记」，还会把你写的长评和读书笔记放进对应条目的页面正文：每篇评论一个标题（链接到原文）加日期和全文；笔记放在「我的读书笔记」下面，每条带页码标题。原文里的图片不搬运，会留一个看原文的链接。重新导入时只会追加页面里还没有的，不会重复。只能读到公开的内容；没标记过的书即使写了评论也不会单独导入。

**豆瓣上的列表**：豆列、图书标签（如「科幻」）、Top250、别人的读过/想读、「选电影」「选剧集」等。两种用法：
- 在豆瓣打开这个列表页，点插件图标 →「批量导入这个页面」；
- 或者在批量导入页切到「豆瓣上的列表」，粘贴链接。

能翻页的列表会顺着「后页」往下读，可以设定最多读几页（标签页可能有几百页）。「选电影」这类往下滚动加载的页面，插件只能读到页面上已经显示出来的条目，所以要先在页面上点几次「加载更多」，再用插件图标导入。
列表页上只有标题和评分，所以每条都会打开详情页补全信息；如果你登录了豆瓣、并且标记过其中某本书，你的状态和评分也会一起带上。导入后会在「来源」字段记上出处，比如「豆列：五颗星经典系列」「标签：科幻」；同一本书从多个列表导入，来源会累加。

读取后进入挑选页：

- 可以按类型、状态（想/在/已）、标记年份、我的评分筛选，或者搜标题、作者、导演；也可以按标记时间、评分、标题排序；
- 「全选这些 / 取消这些」只作用于当前筛选出来的条目；按住 Shift 点击可以连选；
- 默认勾选所有还没导入的。标着「已在 Notion」的条目默认不勾，勾上就会用豆瓣的最新信息更新它；
- 底部会显示已选几条和预计用时。

**写进哪个数据库**：挑选页下方可以为图书、电影、剧集分别选：
- **默认**：设置里的库（「我的书库」「我的影院」「我的剧集」）；
- **新建一个数据库**：名字默认是来源，比如「豆列：五颗星经典系列」，可以改；建在设置里选的页面下；
- **已有的数据库**：列出插件有权限访问的所有数据库，只补缺少的字段，不改已有字段；
- **和电影用同一个库**（剧集专用）：改了电影的库、剧集还在默认库时，会自动切到这一项。

换了库之后，「已在 Notion」会按新的库重新判断，勾选也跟着更新。插件会记住每个来源上次选的库（新建的库下次直接写进去，不会再建一个）。
如果只是想按来源分开看，也可以不建新库：在默认库里用「来源」字段建几个筛选视图即可。

点「开始导入」后可以随时暂停。切到别的标签页时，进度会显示在标签页标题上；关掉页面后再打开会提示继续，勾选的结果也会保留。导入完成后可以直接打开对应的 Notion 数据库。

### 关于豆瓣的访问限制

- 「我的豆瓣标记」用的是豆瓣移动版的接口，每次 50 条，请求间隔 1.5 秒；其他列表页每页间隔 2 秒。
- 详情页每次间隔 3~5 秒（随机）。实测 1.5 秒一条也没被拦，这里刻意放慢，避免你的 IP 被豆瓣限制。
- 如果豆瓣要求安全验证，导入会自动暂停，并给出一个豆瓣链接。打开它，等页面正常显示（有验证就按提示完成），再回来点「继续」。插件不会尝试绕过验证。
- 如果豆瓣返回「请求太频繁」，会自动等 1 分钟、3 分钟后重试，仍不行就暂停。
- 只能导入**公开**的标记。设为「仅自己可见」的标记不会出现在列表里。

## 权限说明

| 权限 | 用途 |
| --- | --- |
| `activeTab`、`scripting` | 读取当前豆瓣页面的信息 |
| `storage`、`unlimitedStorage` | 在本地保存 Token、数据库 ID 和批量导入的进度 |
| `alarms` | 自动同步的定时任务 |
| `offscreen` | 自动同步时在后台解析豆瓣页面（后台脚本本身没有网页解析能力） |
| `m.douban.com`、`www.douban.com` | 批量导入时读取你的标记列表、豆列 |
| `declarativeNetRequestWithHostAccess` + `*.doubanio.com` | 给插件**自己**发出的请求（下载封面、读列表）加上豆瓣 Referer，不影响你的正常浏览 |
| `api.notion.com` | 调用 Notion API |

Token 只保存在本机浏览器里，只会发给 `api.notion.com`。

## 开发

项目没有构建步骤，改完代码在 `chrome://extensions/` 点刷新即可。

```
scraper.js     豆瓣详情页的抓取函数（弹窗和批量导入共用）
collector.js   从任意豆瓣列表页收集条目（弹窗和批量导入共用）；读书笔记列表和全文页的解析
writings.js    书评 / 笔记的 HTML → Notion 段落，以及避免重复追加
douban.js      批量导入：列表数据转换、查重、识别验证页
selection.js   批量导入：筛选和勾选
autosync.js    自动同步：找出变化、分批处理、状态文字
offscreen.*    自动同步时解析豆瓣页面的离屏文档
notion.js      Notion API 客户端，以及字段格式转换
config.js      字段名候选列表、自动建库的结构
databases.js   找到 / 新建数据库，补全缺少的字段
mapping.js     字段对应窗口
background.js  后台：同步、查重、封面上传
popup.*        工具栏弹窗
options.*      设置页
import.*       批量导入页
tests/         单元测试（fixtures 里是豆瓣接口的真实返回样例）
```

运行测试（需要 Node 18+）：

```bash
npm test
```
